## 🎯 设立宗旨

很多人把大模型当成了更高级的搜索框，得到的往往是四平八稳的百科总结。

但大模型最强悍的能力，是充当一名拥有无尽耐心、随叫随到的**苏格拉底式私教**。

**深问（Deep Ask）** 整理了一套系统化的深度提问配方：
- **苏格拉底追问法**：让 AI 不给答案，而是通过连续提问逼迫你思考概念本质；
- **费曼盲区测试**：向 AI 解释你的理解，让 AI 专门挑出你的逻辑漏洞和认知断层；
- **反事实推演**：如果底层假设不成立，现存的系统会发生什么变化。
